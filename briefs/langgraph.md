LangGraph
What it is

LangGraph, created by LangChain, is an open source AI agent framework designed to build, deploy and manage complex generative AI agent workflows. [3]

• LangGraph provides low-level supporting infrastructure for any long-running, stateful workflow or agent. [1]
• Many production systems use both: LangChain’s components (document loaders, vector stores, model interfaces) combined with LangGraph’s stateful orchestration layer. [4]
• Nodes: In LangGraph, nodes represent individual components or agents within an AI workflow. [3]
• Mix deterministic and agentic steps: Combine hand-coded, deterministic logic with LLM-driven decision-making in a single graph. [1]
