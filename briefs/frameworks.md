# Three frameworks

From their own pages. Not a ranking. Nothing was added to make them agree.

LangGraph provides low-level supporting infrastructure for any long-running, stateful workflow or agent. [1]

Nodes in LangGraph represent individual components or agents within a workflow. [2]

A LangGraph graph can mix hand-coded, deterministic logic with model-driven decisions. [1]

CrewAI is an open-source framework focused specifically on autonomous multi-agent orchestration. [3]

CrewAI Flows are event-driven automations with workflow control, single model calls, and native support for crews. [4]

In the OpenAI Agents SDK, tools let agents take actions: fetching data, running code, calling external APIs, and using a computer. [5]

Those agents can also work with other agents and keep context across steps. [6]
